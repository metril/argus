ubo-resources.json is a snapshot of uBlock Origin's scriptlet library, converted to adblock-rust
resources by `convert_ubo_scriptlets` (see examples/gen_resources.rs).

Upstream:   uBlockOrigin/uBlock, src/js/resources/*.js (32 files) + src/js/urlskip.js
Commit:     5934db2a0437a50182c4a8f3da2e0941cf806253 (2026-11-21)
Licence:    GPL-3.0-or-later (uBlock Origin).

Embedded by the default build (cargo feature `bundled-ubo-resources`, on by default; build with
`--no-default-features` to leave it out). See docs/LICENSING.md.

Result:     153 resources, all validated (0 dropped); resources with `requiresTrust` carry the
            trust permission and are only usable from trusted lists.

ubo-redirects.json: the 49 `$redirect` resources of the same commit (src/web_accessible_resources/*
named by src/js/redirect-resources.js; binary files base64) plus AdGuard redirect names, converted
by `convert_ubo_redirects`. Refreshed at runtime together with the scriptlets (map + files fetched
from the same raw base URL), the bundled copy filling any gap.

AdGuard additions: ubo-redirects.json also holds the 10 AdGuard `$redirect` resources uBO lacks
(ati-smarttag, didomi-loader, freewheel-admanager, gemius, matomo, metrika-yandex-tag,
metrika-yandex-watch, naver-wcslog, pardot-1.0, prebid), from AdguardTeam/Scriptlets v2.5.1
(2026-08-25; dist/redirects.json, GPL-3.0; v2.6.0 was under 14 days old). uBO's resource wins
where both exist; the same file-type and script validation applies (`convert_adguard_redirects`).

Offline fallback only: a copy fetched at runtime (or cached in the data dir) takes precedence.

Regenerate: download the files (and src/js/urlskip.js) at the desired commit into a directory, then
  cargo run -p filter-engine --example gen_resources -- <dir> crates/filter-engine/resources/ubo-resources.json \
    <redirect-resources.js> <web_accessible_resources dir> crates/filter-engine/resources/ubo-redirects.json \
    <AdGuard Scriptlets package/dist/redirects.json>
and update this file.
